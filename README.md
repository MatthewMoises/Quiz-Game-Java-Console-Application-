# Quiz-Game-Java-Console-Application-
A console-based quiz game built in Java that challenges players with randomly generated questions across multiple subjects. It features ASCII art for a fun interface, a timed answering system, and a large pool of stored questions to keep the game engaging.

🎮 Features
100+ Stored Questions: Includes General Knowledge plus Filipino, Araling Panlipunan, English, Science, Mathematics, Ethics, Oral Communication, Entrepreneurship, and Personal Development.
Randomized Gameplay: Each round selects 10 random questions from the pool of 100.
Answer Validation: Accepts only valid inputs (A–D).
Timer Mechanic: Players have 10 seconds to answer each question.
Score & Remarks: Displays final score with personalized feedback (Excellent, Very Good, Good, Fair, Needs Improvement).
Replay Option: Players can choose to play multiple rounds.
ASCII Art Interface: Retro-style visuals for menus and notices.

🛠️ Tech Stack
Language: Java
Libraries: java.util.Random, java.util.Scanner
Environment: Console-based application

🚀 How to Play
Run the program in your terminal/IDE.
Enter your Quizzer Name.
Answer each question within 10 seconds by typing A, B, C, or D.
At the end of 10 questions, view your score and remarks.
Choose whether to play again or exit.
